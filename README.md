# CPU Scheduler Simulation

A Python desktop application built with Tkinter for simulating and visualizing CPU scheduling algorithms with interactive Gantt charts and performance metrics.

## Features

- **Supported Algorithms**:
  - First-Come, First-Served (FCFS)
  - Shortest Job First (SJF) – Non-preemptive & Preemptive (SRTF)
  - Priority Scheduling – Non-preemptive & Preemptive
  - Round Robin (RR)
- **Interactive Visualization**:
  - Dynamic Gantt Chart timeline display
  - Step-by-step simulation controls
  - Process table tracking Arrival Time, Burst Time, Priority, and Remaining Time
- **Detailed Performance Metrics**:
  - Turnaround Time (TAT)
  - Waiting Time (WT)
  - Average Turnaround & Waiting Times
  - CPU Utilization & Throughput statistics

## Requirements

- Python 3.x
- Tkinter (included by default with standard Python installations)

## How to Run

Clone the repository and run:

```bash
python main.py
```
